# Perfumy - A Perfume Store Website

## Overview
Perfumy is a simple static website for a perfume store, built using only HTML and CSS. This project demonstrates a clean and elegant layout with smooth styling, making it a great example of basic front-end web development.

## Features
- **CSS Styling:** Enhanced with modern CSS properties for a sleek look.
- **Navigation Bar:** Easy-to-use navigation for better user experience.
- **Product Showcase:** Display of perfume collections in a stylish format.

## Technologies Used
- **HTML5** for structuring the website
- **CSS3** for styling and responsiveness
